# 数据分类

对于爬取出来的数据，大体上可以分为结构化数据和非结构化数据

## 结构化数据

有一定结构的数据，比如json。
处理方式：直接转化为python类型或jsonpath

## 非结构化数据

非结构化数据指的是没有预定义的数据模型或格式的数据，比如 html。
处理方式：正则表达式、xpath









# 数据提取

## jsonpath

JSONPath 是一种用于在 JSON 数据中**定位**和**提取数据**的**查询语言**。

JSONPath 是一门语言：定位和提取数据。

讲这一段的目的 =》体现 python 对象方式获取数据有什么缺点。

需求：需求：找到 sku 对应的值 & 价格。

测试数据：文件：example.json

**通过 python 对象获取目标数据** 

```python
import json

with open("example.json", "r", encoding="utf-8") as f:
    data = json.load(f)
    # 需求：找到 sku 对应的值 & 价格
    # print(data)
    # 标题【组合】
    sku = data["users"][0]["orders"][0]["items"][0]["sku"]
    print(sku)
    # 价格
    price = data["users"][0]["orders"][0]["items"][0]["price"]
    print(price)
```

上面这种方式缺点：格式写的太丑，多个数据的匹配不太友好。

**通过 jsonpath 取目标数据** 

```python
import jsonpath
import json

with open("example.json", "r", encoding="utf-8") as f:
    data = json.load(f)

    sku = jsonpath.jsonpath(data, '$..sku')
    print(sku)
    sku = jsonpath.jsonpath(data, '$..price')
    print(sku)
```

下面这一个针对层数比较多，或数据比较杂的，适合使用。

### 使用步骤

1. 安装：pip install jsonpath 
2. 调用：jsonpath.jsonpath(obj, expr)
   - obj：表示 json 数据【**python 对象类型的**】
   - expr：表示筛选条件【表达式】
3. 返回值：返回路径或值，没有筛选到则返回 false

## xpath

主要用来处理 html 文本数据。

用正则表达式获取数据的缺点？模糊，不精确。

### 使用步骤

1. 安装：pip install lxml 

2. 匹配：

   ```python
   # 导包
   from lxml import etree
   
   # 转换 =》将 html 文本转换成 etree 对象【语法树】
   with open("top250.html", "r", encoding="utf-8") as f:
       # 参数一定是一个 html 文本
       html = etree.HTML(f.read())
       # 使用路径匹配
       res = html.xpath('//title/text()')
       print(res)
   ```

扩展【html】：

1. 标签：以 **<单词>** 格式存在就称为标签。

   **<单词> 内容 </单词>** 在开始和结束标签中间包含的内容都属于这个标签【子元素】。

2. 属性：

   ```html
   <img width="100" alt="末代皇帝" src="https://img3.dou.../public/p452089833.webp">
   ```

   src：属性【修饰，width 宽度，修饰图片的宽度】。

   id：是一个特殊的属性，绝对唯一【ID CARD 身份证】。

通过 xpath 获取数据主要来源：

- 文本内容
- 属性值
