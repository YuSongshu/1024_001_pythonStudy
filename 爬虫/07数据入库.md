1.点击浏览器开发者工具最左边的“元素”

3.点击页面中需要的数据

## python 操作 excel

​    python 操作文档【自动化办公】。

1. 安装：pip install openpyxl

2. 打开文档【文档是否存在？】
    - 文档存在：直接打开
        获取文档名称：test.xlsx

        ```
        import openpyxl
        # 文件路径（可以是相对路径或绝对路径）
        file_path = "test.xlsx"
        wb = openpyxl.load_workbook(file_path)
        ```

    - 文档不存在：创建

        ```
        wb = openpyxl.Workbook()
        ```

3. 打开表单
    - 已存在：
        通过名称访问特定工作表：

        ```
        wb.active
        wb['Sheet1']
        ```

    - 不存在：

        ```
        wb.create_sheet('NewSheet')
        ```

4. 写入数据到文档

    ```
    sheet.append(['数据1', '数据2'])
    ```

## 数据库

数据库软件：
​        MySQL、Oracle、MongoDB、Redis =》MongoDB【排名靠前，公司选择】
​            MySQL

MongoDB 是一个数据库软件。

​    MongoDB 概念：
​        MongoDB 数据库软件   =》excel 文档软件

​        数据库              =》excel 文档

​        集合                =》表单

​        文档                =》一行数据

​        字段                =》标头【标题 =》列名称】



python 操作 MongoDB：
	安装：

```
pip install pymongo
```

​	导包：

```
import pymongo
```

​	连接：

```
client = pymongo.MongoClient("localhost", 27017)
```

​	数据库和集合：

```
### 获取数据库对象
db = client["douban"]
### 获取集合对象
collection = db["top250"]
mongo 中，数据库和集合，不需要单独的创建。
```
