## window

window 是浏览器环境中的一个核心全局对象，它代表了浏览器窗口。在浏览器中存在，但是在 node 环境中不存在的东西。



## 环境介绍

执行 JavaScript 代码时，环境 指的是代码 运行所需的上下文 和 基础设施，它定义了 变量、函数 等资源的访问规则、生命周期及可用 

API。

我们在 pycharm 中执行 js 代码需要安装 node.js，所以它是通过 node.js 环境来执行的【我们称呼它为 node 环境】。

而浏览器在我们没有安装 node.js 之前也可以正常运行，所以它并不依靠 node.js 运行，而是浏览器自己的环境【我们称为它为 浏览器 

环境】。



**为什么需要补环境**

由于 浏览器 和 node 的差别，会导致浏览器的 js 代码在 node 没有办法执行。js 代码会根据浏览器的这些属性来判断你是不是在真正的

浏览器执行的代码，要不是正确的浏览器环境则不会返回正确的数据信息。

```
if (typeof window !== 'undefined') {
    console.log('这是一个浏览器')
} else {
    console.log('这是一个node')
}
```

简单的补环境

```
var window = {}
if (typeof window !== 'undefined') {
    console.log('这是一个浏览器')
} else {
    console.log('这是一个node')
}
```



## 手动补环境

手动补环境是最基础的一种，当我们运行 js 代码的时候，提示缺少什么，就补充什么。比如：

1.缺少 window，在 node 环境中，我们就创建一个 window，然后给其赋值为 global 或者赋值为一个空对象。

2.如果缺少的是其他的一些对象，直接先赋值为空对象即可，后面如果还有对该对象属性或方法的检测，就再为其赋值即可。

3.如果缺少的是函数，则将其赋值为一个函数，函数里面模拟实现类似功能，比如返回与浏览器返回一样的结果。

4.如果是一个属性，直接查看值的结果并赋值即可。
总的来说，我们所补的内容，都是基于浏览器的环境，缺什么在浏览器中查看即可。下面来看看在实际案例中的运用。



本质:把本地的代码报错的地方找到网页对应的地方打断点,再将网页控制台返回的内容对本地的代码内容进行替换





## proxy 框架吐环境

将要补的环境通过 proxy 框架打印出来，我们根据吐出的环境补充即可

### proxy 框架使用方式

放到中间

```
// 补环境的代码位置


// ------- 补环境自吐代码开始 -------
function myProxy(proxy_array) {
    for (var i = 0; i < proxy_array.length; i++) {
        handler = `{
            get: function(target, property, receiver) {
                console.log("方法: get ,", "对象: ${proxy_array[i]} ,", "属性: ${proxy_array[i]}."+property,", 属性类型:", typeof property, ", 属性值类型:", typeof target[property]);
                return target[property];
            },
            set: function(target, property, value, receiver) {
                console.log("方法: set ,", "对象: ${proxy_array[i]} ,", "属性: ${proxy_array[i]}."+property,", 属性类型:", typeof property, ", 属性值类型:", typeof target[property]);
                return Reflect.set(...arguments);
            }
        }`;
        eval(`try {
            ${proxy_array[i]};
            ${proxy_array[i]} = new Proxy(${proxy_array[i]}, ${handler})
        } catch (e) {
            ${proxy_array[i]} = {};
            ${proxy_array[i]} = new Proxy(${proxy_array[i]}, ${handler})
        }`);
    }
}

proxy_array = ['window', 'document', 'location', 'navigator', 'history', 'screen'];
myProxy(proxy_array);
// ------- 补环境自吐代码结束 -------

// 网页代码
window.location;
navigator.user_agent;
```



```
方法: get , 对象: window , 属性: window.location , 属性类型: string , 属性值类型: undefined
方法: get , 对象: document , 属性: document.head , 属性类型: string , 属性值类型: undefined
方法: get , 对象: document , 属性: document.getElementsByTagName , 属性类型: string , 属性值类型: undefined

```

注：proxy 必须放在中间





## jsdom 补环境

jsdom是一个纯粹由 javascript 实现的一系列 web 标准，它允许在 Node.js 环境中模拟浏览器环境，提供类似浏览器中的 DOM 操作能力。对于我们补环境来说，它里面包含浏览器环境，我们可以直接使用，这样我们补起来就会简单很多

### 安装 jsdom

```
npm install jsdom@19.0.0
```

注    

node 安装库安装到项目根目录。

### 使用

```
const jsdom = require("jsdom");			#相当于导包
const { JSDOM } = jsdom;			#jsdom 模块内部导出了 JSDOM 构造函数（核心类，用来模拟浏览器 DOM 环境），直接从模块对象中提取 JSDOM，简化后续代码。

// 实例化 dom 环境，生成包含 dom 树的虚拟环境 =》 这里创建了基础 html 文档结构
const dom = new JSDOM(`<!DOCTYPE html><p>Hello world</p>`);
//通过 dom 对象调用补环境

//网页代码

```

示例

```
const jsdom = require("jsdom");
const { JSDOM } = jsdom;

// 实例化 dom 环境，生成包含 dom 树的虚拟环境 =》 这里创建了基础 html 文档结构
const dom = new JSDOM(`<!DOCTYPE html><p>Hello world</p>`);

// 需要哪个环境，通过 dom 对象调用即可
window = dom.window;
document = window.document
location = window.location;
navigator = window.navigator;
history = window.history;
screen = window.screen;
// 'window', 'document', 'location', 'navigator', 'history', 'screen'

window.HTMLCanvasElement.prototype.getContext = function(){}	#jsdom 轻量补环境，不安装 canvas 第三方图形库
```
