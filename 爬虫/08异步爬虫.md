# 08_异步爬虫

异步处理不用阻塞当前线程来等待处理完成，而是允许后续操作，直至其它线程将 处理完成，并回调通知此线程。

简单来说爬取信息会有步骤，如发送请求，网络等待，翻页......    每一步会花时间，故海量采集极慢



异步爬虫是基于**非阻塞 IO、协程、事件循环**实现的高并发爬虫，核心逻辑：

发送网络请求后不会原地阻塞等待服务器返回，而是立刻切换去发起下一个请求；等某个页面响应完成，再切回来解析页面。





## 进程 

简单来说一个应用或文件就是一个进程



## 线程

进程内部执行单元

简单来说，一个进程里的某种功能就是一个线程



## 协程

是运行在单线程内部的并发方案，由程序自身调度，不需要操作系统内核参与切换。



异步爬虫就是协程



## 协程常用 API

### asyncio

Python 的 asyncio 模块是标准库中用于编写异步 I/O 操作的模块，基于协程和 事件循环机制实现单线程高并发，特别适用于网络请求、

文件 I/O 等场景

使用

```
import asyncio
async def main():
await asyncio.sleep(1)
print("Done")
asyncio.run(main())
```



#### 协程函数

```

```

输出

协程对象（返回的是对象）

协程任务要执行，需要使用 asyncio.run

| asyncio.run()         | 启动异步程序                                      | 必用     |

#### await关键字

顾名思义,一个等待,只要是 async 修饰的都要加 await



#### 应用

```
import asyncio
async def test1():
    print('111')
    await asyncio.sleep(2)
    print('111-end')
async def test2():
    print('222')
    await asyncio.sleep(2)
    print('222-end')

async def main():
    # test1()
    # test2()
    await asyncio.gather(test1(), test2())

asyncio.run(main())
```

输出

```
111
222
# 等待2秒
111-end
222-end
```



调用 `async def 函数()` 只会得到协程对象，不会执行函数逻辑

必须通过 `await` / `create_task` / `gather` 交给事件循环调度才能运行

代码中单独写 `test1()` 属于无用代码，还会触发未等待协程警告,运行报错



##### await asyncio.sleep(2)与time.sleep(2)

```
import asyncio
import time


async def test1():
    print('111')
    time.sleep(2)
    print('111-end')


async def test2():
    print('222')
    time.sleep(2)
    print('222-end')


async def main():
    await asyncio.gather(test1(), test2())

asyncio.run(main())
```

输出

```
111
# 等待2秒
111-end
222
# 再等待2秒
222-end
```

`time.sleep()` 是同步阻塞函数，会直接阻塞整个异步事件循环，CPU 卡死等待，不会让出控制权。

哪怕用 `asyncio.gather` 并发封装，执行到 `time.sleep` 时程序串行执行，也得失去异步并发效果。



注

async 函数内不能调用同步阻塞 IO（time.sleep、requests、文件同步读写等），会破坏并发；

即 在异步 async 里面不能用同步方法





##### 用asyncio.create_task()管理

```
import asyncio

async def test1():
    print('111')
    await asyncio.sleep(2)
    print('111-end')

async def test2():
    print('222')
    await asyncio.sleep(2)
    print('222-end')

async def main():
    task1 = asyncio.create_task(test1())
    task2 = asyncio.create_task(test2())
    await task1
    await task2

asyncio.run(main())
```

一样的效果



##### 用 asyncio.Semaphore()  限制并发数

```
import asyncio

sem = asyncio.Semaphore(3)
async def test(id):
    # 在协程里面碰到 with 要加上 async
    async with sem:
        print(f'{id}')
        await asyncio.sleep(2)
        print(f'{id}-end')

async def main():
    # 通过循环创建多任务,任务列表，保存所有任务
    tasks = []
    for i in range(100):
        task = test(i + 1)
        # 将任务添加到列表中
        tasks.append(task)
    # 将上面的任务分解传递
    await asyncio.gather(*tasks)

asyncio.run(main())
```



## 异步请求-aiohttp

相当于requests,但requests是同步方法,不能在协程中,故要改库,即 aiohttp

安装：pip install aiohttp



### 使用

```
创建会话对象：
    async with aiohttp.ClientSession() as session:
发送请求：
    async with session.get('https://www.example.com') as response:
    sync with session.post('https://www.example.com', data=data) as response:
获取响应内容
    text_content = await response.text()
    json_content = await response.json()
    byte_content = await response.read()
```

示例

```
import aiohttp
import asyncio

headers = {
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/143.0.0.0 Safari/537.36 Edg/143.0.0.0',
}

async def send_request(url):
    # 创建发送请求对象
    async with aiohttp.ClientSession() as session:
        async with session.get(url, headers=headers) as response:
            text_content = await response.text()
            print(text_content)


asyncio.run(send_request('https://www.baidu.com/'))
```

```
for thread in thread_list:
    thread.start()
```



### 线程池

ThreadPoolExecutor()

导包: from concurrent.futures import ThreadPoolExecutor

应用

```
import threading
import time
from concurrent.futures import ThreadPoolExecutor

def test(name):
    print(f"hello - {name}")
    time.sleep(2)
    print(f"hello - {name} - end")


with ThreadPoolExecutor(max_workers=2) as pool:
    for i in range(10):
        pool.submit(test,  i)
```

线程是操作系统随机调度，执行顺序不保证

两个线程同时跑，`print` 是 IO 操作，会被操作系统打断切换线程，打印语句会互相穿插

故要锁

```
import threading
import time
from concurrent.futures import ThreadPoolExecutor

print_lock = threading.Lock()  # 创建锁

def test(name):
    with print_lock:  # 打印前加锁
        print(f"hello - {name}")
    time.sleep(2)
    with print_lock:
        print(f"hello - {name} - end")

with ThreadPoolExecutor(max_workers=2) as pool:
    for i in range(10):
        pool.submit(test, i)
```



线程池 与 asyncio 协程

线程池 ：OS 调度，顺序随机，共享资源会竞争，需要锁(否则会粘连,打印乱序)；

asyncio 协程：单线程顺序调度，同一时刻只有一段代码运行，打印不会乱序，无需锁。

```
if __name__ == '__main__':			#没它报错

            pool.submit(test,  i)
```
