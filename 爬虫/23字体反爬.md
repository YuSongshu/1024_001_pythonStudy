# 23字体反爬

字体反爬是将关键性数据对应于其它Unicode编码，浏览器使用该页面自带的字体 文件加载关键性数据，正常显示

## 实现原理

字体反爬是一种通过字体映射技术来保护网页数据的一种技术，通过字体文件中的 Unicode与字形对应关系（如uniE630映射为数字2）实现。其实现方式为： 

```
// 通过 @font-face 规则注册名为 encrypt-font 的自定义字体 
@font-face { 
	font-family: 'encrypt-font'; 
	// 指定字体文件路径为 static_font.woff 
	src: url('static_font.woff'); 
} 
// 页面所有文本使用 encrypt-font 字体渲染 
body {  
	font-family: encrypt-font;  
}
```

示例

```
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Title</title>
    <style>
        @font-face {
            font-family: SelfFont;
            src: url("self.woff");
        }

        body {
            font-family: SelfFont;
        }
    </style>
</head>
<body>
<h1>
    年龄：bg
</h1>
<h2>
    出生年月日：caai/ab/ab<br/>
</h2>

</body>
</html>
```

### fonttools

FontTools是一个Python库，它提供了一组用于操作字体的工具和API。这个库可以用来解析、 修改、创建和操作字体文件

#### 使用

安装：pip install fonttools

导包：from fontTools.ttLib import TTFont

创建字体对象：font = TTFont('字体文件名')

转换为稍微能看懂的东西（xml）：font.saveXML('字体文件名')

获取映射关系（unicode 码点：字形名称）：maps = font.getBestCmap()

​	得到的是字典对象



示例

```
from fontTools.ttLib import TTFont

font = TTFont('self.woff')

font.saveXML('self.xml')

# 获取映射关系【重要方法】
# unicode 码点：字形名称
maps = font.getBestCmap()
# print(maps)
for k, v in maps.items():
    print(f"{k}: {v}")
```







### Pillow

Pillow是Python的一个第三方图像处理库，提供了广泛的文件格式支持和强大的图 像处理能力

#### 使用

安装：pip install Pillow

导包：from PIL import Image, ImageFont, ImageDraw

​	Image: 图片、画布，ImageDraw：笔，ImageFont：字体

创建画布：img = Image.new("模式", (长, 宽), color="背景颜色")

创建画笔：draw = ImageDraw.Draw(img)

设置字体：font = ImageFont.truetype(字体文件位置, size=字体大小)

画图：draw.text((x, y), 内容, font=字体 ，font_size=大小, fill='颜色')

保存图片：img.save("图片名称")



示例

```
from PIL import Image, ImageDraw, ImageFont

img = Image.new("RGB", (200, 200), "white")
draw = ImageDraw.Draw(img)

# 字体对象设置
font= ImageFont.truetype("self.woff", size=50)

draw.text((70, 70), 'a', font=font, fill='black')
img.save('a.jpg')
#输出在画布上的是self.woff里对应的0

```

但得到的是图片，要得到文本可以用 ddddocr

from PIL import Image, ImageDraw, ImageFont

### 应用

chr 方法是将 unicode 码点转换为字符的方法

```
from fontTools.ttLib import TTFont
from PIL import Image, ImageDraw, ImageFont
import ddddocr

def get_font_map():
    font = TTFont('self.woff')
    return font.getBestCmap()

def draw_font(text, name):
    img = Image.new("RGB", (200, 200), "white")
    draw = ImageDraw.Draw(img)

    font = ImageFont.truetype("self.woff", size=100)
    mi = chr(text)
    draw.text((70, 70), mi, font=font, fill='black')
    return mi, ocr_font(img)


def ocr_font(img):
    ocr = ddddocr.DdddOcr(show_ad=False)
    res = ocr.classification(img)
    return res


if __name__ == '__main__':
    ds = get_font_map()

    font_maps = {}
    for k, v in ds.items():
        key, value = draw_font(k, v)
        font_maps[key] = value

    print(font_maps)
```



## 静动态字体文件

在实战案例中，有的网站(如：58同城...)中有两个字体文件，通过翻页对比发现一个不变一个改变，其中不变为静态字体文件，改变为动态字体文件



### 案例

58同城

单页

```
# 处理字体的时候，保证动态字体文件和页面文本对应

# 3.28 - %.折- 明文与密文
from fontTools.ttLib import TTFont
from PIL import Image, ImageDraw, ImageFont
import ddddocr
import re
import base64
from lxml import etree

def get_font_map():
    font = TTFont('dong3.ttf')
    return font.getBestCmap()

def draw_font(text, name):
    img = Image.new("RGB", (200, 200), "white")
    draw = ImageDraw.Draw(img)

    font = ImageFont.truetype("dong3.ttf", size=100)
    mi = chr(text)
    draw.text((70, 70), mi, font=font, fill='black')
    return mi, ocr_font(img)


def ocr_font(img):
    ocr = ddddocr.DdddOcr(show_ad=False)
    res = ocr.classification(img)
    return res

def send_requests():
    with open("3.html", "r", encoding="utf-8") as f:
        html = f.read()

        base64_data = re.findall("data:application/font-ttf;charset=utf-8;base64,(.*?)'", html)[0]
        print(base64_data)
        with open("test.ttf", "wb") as f:
            f.write(base64.b64decode(base64_data))

        tree = etree.HTML(html)
        li_list = tree.xpath('//*[@id="list"]/ul/li')
        prices = []
        for li in li_list:
            title = li.xpath('./div/a/div[2]/h2/span/text()')[0].strip()
            price = li.xpath('./div/a/div[3]/b/text()')[0]
            prices.append(f'{title}:{price}')
        return prices

if __name__ == '__main__':
    ds = get_font_map()

    font_maps = {}
    for k, v in ds.items():
        key, value = draw_font(k, v)
        font_maps[key] = value


    prices = send_requests()
    for price in prices:
        for k, v in font_maps.items():
            price = price.replace(k, v)
        price = price + "万元"		#解密后加是因为字体文件里也有万对应的明文，解密前加会乱码
        print(price)

```
