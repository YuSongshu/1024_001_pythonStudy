## 中间件

Scrapy中间件是一个处理Scrapy请求和响应的机制，Scrapy中间件分为下载器中间件（loaderMiddleware）和爬虫中间件（SpiderMiddleware）。

### SPIDER_MIDDLEWARES（爬虫中间件）

SPIDER_MIDDLEWARES（爬虫中间件）：夹在引擎和爬虫中间

```
SPIDER_MIDDLEWARES = {
	爬虫中间件: 优先级,
}
```



### DOWNLOADER_MIDDLEWARES（下载器中间件）

DOWNLOADER_MIDDLEWARES（下载器中间件）：夹在引擎和下载器中间

```
DOWNLOADER_MIDDLEWARES = {
	下载器中间件: 优先级,
}
```

1.process_request：处理请求，中间件中添加请求头

```
def process_request(self, request, spider):
    # 中间件中添加请求头
    request.headers['User-Agent'] = 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/146.0.0.0 Safari/537.36 Edg/146.0.0.0'
    request.headers['referer'] = 'https://www.baidu.com/'
    # 添加代理：后面的值是完整的 ip 代理地址
    request.meta["proxy"] = "http://127.0.0.1:8080"
```

注：可以配合ua池



2.process_response：处理响应





### 使用

1.创建中间件类（处于 middlewares.py 文件中）

2.中间件处理请求和响应 class 中间件类:

```
def process_request(self, request, spider):
	request.headers['User-Agent'] = "self user-agent" return None
```

3.配置中间件 （处于 settings.py 文件中）

​	中间件配置好后（取消注释），发送请求后，自动执行。

## CrawlSpider

CrawlSpider 是 Scrapy 框架提供的一个高级爬虫类，它封装了许多常见爬取网站 的逻辑，使得编写爬虫更加简单和快速，CrawlSpider 类继承自 scrapy.Spider 类，并额外提供了一些功能来处理网页链 接的跟踪和提取，并自动生成新的请求



### 使用

1.创建一个 CrawlSpider 子类 通过命令快速生成：

```
scrapy genspider -t crawl <爬虫名> <allowed_domail>
scrapy genspider -t crawl cdb https://movie.douban.com/top250
```

2.定义规则 spider 中的 rules 属性： 

```
from scrapy.linkextractors import LinkExtractor
from scrapy.spiders import CrawlSpider, Rule
rules = (Rule(LinkExtractor(allow=r"Items/"), callback="parse_item", follow=True),)
```

rules 是**元组**，末尾逗号不能丢 `(...,)`，少逗号会报错。

3.编写回调函数 
4.运行爬虫





| 对比项   | 普通 Spider                                      | CrawlSpider                                                  |
| -------- | :----------------------------------------------- | ------------------------------------------------------------ |
| 链接提取 | 手动写 xpath/css 提取链接，手动`yield Request()` | 通过`Rule` + `LinkExtractor`自动提取页面内链接，自动生成请求 |
| 主要用途 | 已知目标 URL，少量页面、定向抓取                 | 全站爬取、递归爬网页、分页、整站采集                         |
| 回调函数 | `parse()`，自己解析、自己发请求                  | **不能重写 parse ()**，用`rules`里的`callback`做解析；parse 被父类占用做链接提取逻辑 |
| 分页处理 | 自己提取下一页链接，手动构造 Request             | 规则配置即可自动跟进下一页                                   |
| 灵活性   | 极高，完全自定义逻辑                             | 受 Rule 规则约束，适合规则清晰的网站，复杂反爬 / 特殊逻辑不如普通 Spider 灵活 |





## 分布式

分布式是指将不同的数据分散到不同的地理位置进行存储和计算，以获得更好的性 能和扩展性

### scrapy-redis 

Scrapy-redis是一个用于Scrapy框架的Redis扩展，它可以将Scrapy的爬虫和中间件存储在 Redis中，以便于管理和控制爬虫的访问。

#### 使用

安装：pip install scrapy-redis 

创建 spider，修改 spider 的父类为 RedisSpider 

​	from scrapy_redis.spiders import RedisSpider 

修改 start_urls 为 redis_key 

​	这个 key 需要在 redis 中设置 key: url 

```
# Redis 的命令
LPUSH key https://www.bilibili.com/		# key 就是 redis_key 的值

```

修改配置文件（不需要记，直接复制粘贴就行） 

```
# redis 配置
REDIS_HOST = 'localhost'  # 本地的，不要改
REDIS_PORT = 6379  # 默认的不要改
REDIS_DB = 0  # 表示数据库
#启用 Scrapy-Redis 扩展
# 使用 scrapy_redis.scheduler.Scheduler 作为调度器
SCHEDULER = "scrapy_redis.scheduler.Scheduler"
# 使用 scrapy_redis.dupefilter.RFPDupeFilter 作为去重过滤器
DUPEFILTER_CLASS = "scrapy_redis.dupefilter.RFPDupeFilter"
# 配置持久化支持，在爬虫关闭时是否保留 Redis 中的请求队列和去重集合，
# 可选值为 True 和 False，默认为 False
SCHEDULER_PERSIST = True
```
