## ddddocr

ddddocr 是一个由国人开发者开发的、专门用于识别各种验证码（Captcha） 的  Python 第三方库，它的功能非常实用、轻量、高效，且对中文和常见验证码类型支持非常好

注：大批量文字别用

### 安装

```
pip install ddddocr
```

注：python解释器版本要3.12 及以下

### ddddocr常用API

| 功能               | API 方法                      | 参数                       | 返回值                      | 说明                         |
| ------------------ | ----------------------------- | -------------------------- | --------------------------- | ---------------------------- |
| 初始化 OCR 对象    | ddddocr.DdddOcr()             | 无 / 可选参数              | OCR 对象                    | 创建一个识别器               |
| 识别普通文字验证码 | ocr.classification(img_bytes) | 图片二进制数据             | 识别出的字符串（如 "1234"） | 最常用！支持数字、字母、中文 |
| 识别滑块验证码     | ocr.slide_match(bg, slide)    | 背景图 bytes、滑块图 bytes | 滑动距离（像素 int）        | 用于滑块类验证码             |
| 目标检测（点选类） | ocr.detection(img_bytes)      | 图片二进制                 | 目标坐标等信息              | 用于点选类验证码（较复杂）   |

详细文档见 https://gitee.com/platformcn/ddddocr

ddddocr.DdddOcr()创建的识别器默认夹带私货（广告），通过参数可以去除

```
ocr = ddddocr.DdddOcr(show_ad=False)
```





## 案例

### 中大网校

https://user.wangxiao.cn/login

验证码

```
data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAUAAAACMCAIAAACCr+eGAAAjy...
```

解析：image/png文件，base64方式加密，逗号后是密文

要获取他先要请求，找到请求（用部分密文进行搜索找到固定发送验证码的url），复制curl（bash）用工具生成python请求（过长不予展示）

```
import base64
import requests

def decode_base64(data):
    image_bytes = base64.b64decode(data)
    with open("test.png", "wb") as f:
        f.write(image_bytes)
response = requests.post('https://user.wangxiao.cn/apis//common/getImageCaptcha', cookies=cookies, headers=headers)        
base64_data = response.json()["data"].replace('data:image/png;base64,', "")  #多余的替换为空
decode_base64(base64_data)
```
