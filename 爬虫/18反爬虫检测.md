## navigator.webdriver

navigator.webdriver：关键参数，如果是自动化打开浏览器其值是Ture

有些网站会检测其值实现反爬

### 解决方案

添加初始化脚本

```
js = "Object.defineProperties(navigator, {webdriver:{get:()=>false}});"
page.add_init_script(js)
```



大佬的js反爬文件ai

D:\tool\playwright进阶\素材\stealth.min.js

使用

```
with open("stealth.min.js", 'r', encoding="utf-8") as f:
    page.add_init_script(f.read())

page.goto('https://bot.sannysoft.com/')
```





## 启动本地浏览器

为什么要启动本地浏览器

无痕窗口：没有浏览痕迹

我们用脚本相当于无痕窗口，对于要登录的网站的数据采集，每次都要重新登录，所以我们启动本地浏览器就有浏览痕迹

注：

启动本地浏览器不要用你自己安装的浏览器【概率可行】，用 playwright 安装的

### 启动方式

#### playwright 打开

```
browser = pw.chromium.launch_persistent_context(
        # 用户数据路径文件
	user_data_dir=r'用户数据路径文件',
        # 浏览器的路径
	executable_path=r"浏览器的路径",
        # 显示浏览器的界面
	headless=False
)
```

用户数据路径文件：C:\Users\AppData\Local\ms-playwright\chromium-1200\chrome-win64\data_001'（可以新建）

​	用户数据不建议改

谷歌浏览器的路径：C:\Users\AppData\Local\ms-playwright\chromium-1228\chrome-win64\chrome.exe



#### subprocess 打开

subprocess是什么？

​	subprocess 是 Python内置模块，用来创建操作系统子进程，执行外部 exe、cmd、shell 命令。

```
cmd = f'python --version'
subprocess.Popen(cmd)
```

原理：通过subprocess执行命令打开浏览器

```
import subprocess
import time
from playwright.sync_api import sync_playwright

# 准备浏览器
path = r'浏览器的路径'
params = "--remote-debugging-port=7899"   #远程调试端口，连接浏览器，用于操控浏览器
cmd = f'"{path}" {params}'
subprocess.Popen(cmd)

# 连接浏览器
browser = pw.chromium.connect_over_cdp('http://127.0.0.1:7899')

```

示例

```
import subprocess
import time
from playwright.sync_api import sync_playwright

path = r'C:\Users\AppData\Local\ms-playwright\chromium-1228\chrome-win64\chrome.exe'
params = "--remote-debugging-port=7899"
cmd = f'"{path}" {params}'
subprocess.Popen(cmd)

time.sleep(2)


with sync_playwright() as pw:
    browser = pw.chromium.connect_over_cdp("http://127.0.0.1:7899")
    context = browser.new_context()
    page = context.new_page()

    page.goto('https://www.baidu.com/')

    page.wait_for_timeout(100000)
    time.sleep(3)
```

准备浏览器时会打开一个任务管理器（程序），`goto`时也会打开一个任务管理器，所以会有两个任务管理器

解决方案

```
# context = browser.new_context()
# 获取第一个上下文管理器
context = browser.contexts[0]

# 网页同理
#page = context.new_page()
page = context.pages[0]

page.goto('https://www.baidu.com/')
page.wait_for_timeout(100000)
time.sleep(3)
```
