# 16_类型转换

## 1.int(x)：将数据x转换成整数

x:可以是浮点数/被引号包围的整数

```
print(int(10.5))  # 截取整数部分，不会四舍五入
print(int('55'))
```

注：

print(int('55.5'))  # 报错ValueError: invalid literal for int() with base 10: '55.5'



## 2.float(x)：将数据x转换成浮点数

x:可以是整数/浮点数/被引号包围的整数/被引号包围的浮点数

```
print(float(10))  # 会在整数后补一位小数
print(float(10.5))
print(float('55'))
print(float('55.5'))
```



## 3.str(x)：将数据x转换成字符串

x:可以是任意数据类型

```
print(str(10))
print(str(10.5))
print(str('aa'))
print(str([12, 10, 55]))
print(str((12, 10, 55)))
# 字符串数据在控制台输入时，不会显示出引号
# 在控制台查看数据两边的引号，f"{变量=}"		调试语法（3.8+）
print(f"{str(10)=}")
print(f"{str(10.5)=}")
print(f"{str('aa')=}")
print(f"{str([12, 10, 55])=}")
```



如果原先的数据带符号：列表、元组、字典、集合，转换成字符串后，符号也是字符串的一部分

res = str([12, 10, 55])  # str
print(res[0])  # 取字符串中第一个元素

单纯转换列表中的元素作为字符串

res2 = [str(i) for i in [12, 10, 55]]
print(res2)

将列表中的元素提取出来，作为字符串存放

res3 = "".join(res2)
print(f"{res3=}")





## 4.bool(x)：将数据x转换成布尔值

x:可以是任意数据类型

非零数据为真，数据为零或为空时为假

```
print(bool(10))
print(bool(0))
print(bool(""))
```



## 5.eval(x):将字符串两边的引号去掉，把中间内容作为python表达式执行

注：

eval()是存在安全风险的函数

与sql注入同理

```
print(eval('10+5'))  
# '10+5'  -->   10+5  --> 15
print(eval('print("hello")'))  
# str-->去掉引号-->执行引号中的语句-->打印hello
# 使用eval()函数时，如果引号中的数据类型错误，会报错SyntaxError: invalid syntax
print(eval('10+(12, 11)'))  
# '10+(12, 11)'  -->   10+(12, 11)  --> + 两边的数据类型不一致，报错
```

## 8.list(x)：将数据x转换成列表

x:必须是可迭代对象
可迭代对象：字符串、元组、集合、字典

```
l1 = list('hello')
print(l1)
l2 = list((1, 2, 3))
print(l2)
l3 = list({1, 2, 3})
print(l3)
l4 = list({'a': 1, 'b': 2})
print(l4)  # 列表中存放的是字典的键key
l5 = list([1, 2, 3])
print(l5)
```

输出

```
['h', 'e', 'l', 'l', 'o']
[1, 2, 3]
[1, 2, 3]
['a', 'b']
[1, 2, 3]
```

## 11.dict(x)：将数据x转换成字典

x:必须是可迭代对象,且元素长度为2

不包含字符串

```
l1 = [('a', 1), ('b', 2), ('c', 3)]
print(dict(l1))
tu = (('a', 1), ('b', 2), ('c', 3))
print(dict(tu))
```

输出

```
{'a': 1, 'b': 2, 'c': 3}
{'a': 1, 'b': 2, 'c': 3}
```



## 12.zip(可迭代对象1, 可迭代对象2)：返回的是一个zip对象，不是直接的数据

把多个可迭代对象（列表 / 元组 / 字符串）按位置配对，返回一个 一次性迭代器（节省内存）



```
l1 = [1, 2, 3]
l2 = ['a', 'b', 'c']
res = zip(l1, l2)
print(res, type(res))  	#<zip object at 0x0000025AC8F4A940> <class 'zip'>
# 转列表查看
print(list(res))
```



**获取zip对象中的数据-->迭代zip对象-->数据以元组形式存放**

```
for i in res:
	print(i)
```



**转换成列表**

```
res2 = list(res)
print(res2)  # [(1, 'a'), (2, 'b'), (3, 'c')]
```



**转换成字典**

可迭代对象只能是2个

```
res3 = dict(res)
print(res3)  # {1: 'a', 2: 'b', 3: 'c'}
```



**只能遍历(转换)一次,只能转换成可迭代对象**

```
l1 = [1, 2, 3]
l2 = ['a', 'b', 'c']
res = zip(l1, l2)
for i in res:
    print(i)
print(list(res))
```

输出

```
(1, 'a')
(2, 'b')
(3, 'c')
[]
```

解决方案：转成别的类型



**如果可迭代对象中的元素长度不一致，以短的元素为准**

```
l3 = [1, 2, 3, 4]
l4 = ['a', 'b', 'c']
res4 = zip(l3, l4)
print(list(res4)) 
```

输出

```
[(1, 'a'), (2, 'b'), (3, 'c')]
```



**多对象打包**

```
a = [1,2]
b = [3,4]
c = [5,6]
print(list(zip(a,b,c)))
```

输出

```
[(1, 3, 5), (2, 4, 6)]
```







## 总结

int():不能转换被引号包围的浮点数

str():在转换列表、元组、字典、集合时，符号也作为字符串的一部分

eval():存在安全风险的函数

dict():可迭代对象的元素长度必须为2

zip():可迭代对象中的元素长度不一致，以短的元素为准
