# 24_多态

含义：不同类的对象使用相同的方法，得到不同的结果

优势：

提高代码复用性：可以编写通用的代码处理不同类型的对象

增强可扩展性：添加新的类不需要修改现有代码

提高可维护性：降低代码间的耦合度

增加灵活性：运行时可以动态决定具体调用哪个方法



## python内置的多态实现

str + str 实现的功能：字符串的拼接

int + int 实现的功能：数字的相加

结论：不同类的对象，使用相同的操作方法+，得到不同的结果



## 自定义代码实现多态

### 继承+方法的重写(最常见)

```
class Animal:
    def eat(self):
        print("进食")


class Dog(Animal):  
    def eat(self):  
        print("吃狗粮")


class Cat(Animal):
    def eat(self):
        print("吃猫粮")


def port(obj: Animal):				#子类也会返回 True
    # obj.eat()
    if isinstance(obj, Animal):    #子类也会返回 True
        obj.eat()
    else:
        #     print(f"AttributionError: {type(obj)} object没有eat属性")
        print(f"AttributionError: {type(obj)} has no attribute 'eat' ")


# 多态的概念：不同类【狗类/猫类】的对象【dog/cat】，使用相同的方法【eat()】，得到不同的结果【吃狗粮/吃猫粮】
dog = Dog()
dog.eat()
cat = Cat()
cat.eat()

# 通过接口来实现多态
port(Dog())  # 创建狗类的对象，传入到统一接口中
port(Cat())  # 创建猫类的对象，传入到统一接口中
port(str())  # 字符串不属于Animal类的子类，传入到统一接口中，报错
```
