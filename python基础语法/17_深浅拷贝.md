# 17_深浅拷贝

**赋值 = 引用指向**

`b = a`：**a 和 b 指向同一块内存**，改一个另一个跟着变

**浅拷贝 copy**

只拷贝**最外层**，里面嵌套的子对象还是共用同一个

**深拷贝 deepcopy**

指创建一个新的对象，并且递归地复制原对象中包含的所有元素。**层层全部拷贝**，完全独立，改谁都互不影响



深浅拷贝的作用：备份数据  --> 针对可变数据

## copy模块

```
import copy
```



## 浅拷贝

语法格式：新对象 = copy.copy(原对象)

创建新对象(新地址存放新数据)，但新对象中的元素地址和原对象中的元素地址是一样的

```
lst = [12, ['aa', 'cc']]
new_lst = copy.copy(lst)
print(f"原数据地址：{id(lst)}")
print(f"新数据地址：{id(new_lst)}")
```

输出

```
原数据地址：2025023920192
新数据地址：2025023924928
```

查看内部元素地址

```
print(f"原数据元素地址：{id(lst[0])}，{id(lst[1])}")
print(f"新数据元素地址：{id(new_lst[0])}，{id(new_lst[1])}")
```

输出

```
原数据元素地址：140731203832600，1919369793792
新数据元素地址：140731203832600，1919369793792
```

内部元素的地址相同的



修改原数据中不可变元素，创建新对象

lst[0] = 200

修改可变元素时，因为地址相同(共有资源)，原始数据，备份数据没办法做到完全独立，不管修改哪一份数据，数据之间互相影响

```
lst[1].append("dd")  # 修改原始数据
print(f"修改后原数据：{lst}")
print(f"没有修改的新数据：{new_lst}")
```

输出

```
修改后原数据：[12, ['aa', 'cc', 'dd']]
没有修改的新数据：[12, ['aa', 'cc', 'dd']]
```



故使用场景：
需要对象副本、仅备份**顶层结构**、资源有限 / 追求性能时，优先用**浅拷贝**。





## 深拷贝

语法格式：新对象 = copy.deepcopy(原对象)

创建新对象，新对象中的元素地址和原对象中的元素地址是不一样的

```
lst = [12, ['aa', 'cc']]
new_lst = copy.deepcopy(lst)
print(f"原数据地址：{id(lst)}")
print(f"新数据地址：{id(new_lst)}")
print(f"原数据元素地址：{id(lst[0])}，{id(lst[1])}")
print(f"新数据元素地址：{id(new_lst[0])}，{id(new_lst[1])}")

```

输出

```
原数据地址：2677840140352
新数据地址：2677840145088
原数据元素地址：140731203832600，2677840138496
新数据元素地址：140731203832600，2677840457536
```

注

不可变元素地址完全不变，对应上文说的**针对可变数据**



修改可变元素

```
lst[1].append("dd")
print(f"修改后原数据：{lst}")
print(f"新数据：{new_lst}")
```

输出

```
修改后原数据：[12, ['aa', 'cc', 'dd']]
新数据：[12, ['aa', 'cc']]
```



修改原始数据与修改备份数据同理

可以证明原始数据和备份数据的完全独立



## 区别

|          | 浅拷贝                         | 深拷贝                         |
| -------- | ------------------------------ | ------------------------------ |
| 复制层级 | 仅**顶层**（第一层）           | **递归所有层级**（全复制）     |
| 嵌套对象 | 复制**引用地址**，共享同一内存 | 复制**完整内容**，新内存、独立 |
| 修改影响 | 改**嵌套对象**，原对象跟着变   | 改任意层，**原对象完全不变**   |
| 性能开销 | 快、省内存                     | 慢、耗内存（嵌套越深越明显）   |
| 典型场景 | 单层数据、简单结构、性能优先   | 嵌套复杂结构、需完全隔离数据   |
