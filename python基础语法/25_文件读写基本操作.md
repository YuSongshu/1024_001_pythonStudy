## 文件基本操作

### 1.打开文件 open()

语法： f(文件对象) = open("文件位置")

#### 文件位置

相对路径：有参照的路径，以当前文件位置为参照，要打开的文件位置在哪

```
f = open('test1.txt')
```

绝对路径：从计算机硬盘开始，一直到需要打开的文件位置

使用绝对路径时，为了避免\和后面的数字以及字母混杂在一起，需要使用r(原生字符)

```
f = open(r'D:\博客\python\python基础语法\附件资料\25\test1.txt')
```

但也可以在\前加一个\，取消掉\的转义作用



```
f = open(r'D:\博客\python\python基础语法\附件资料\25\test1.txt')
print(f)
```

输出

```
<_io.TextIOWrapper name='D:\\博客\\python\\python基础语法\\附件资料\\25\\test1.txt' mode='r' encoding='cp936'>
```

name="文件路径"

mode="访问模式"，默认情况下以只读模式'r'打开文件

encoding="编码格式"，默认情况下，以cp936编码格式打开文件



距离远用绝对路径

距离近用相对路径



加入参数，改变默认参数

open(name="文件路径", mode="访问模式", encoding="编码格式")



#### 访问模式

r/w/a/+

r:只读模式，打开文件后只能读取文件中的内容

w:只写模式，打开文件后只能往文件中写入内容(数据的覆盖)（本质：以w 模式打开会清空文件）

a:追加模式，在文件末尾追加新的内容

+:可读可写，既可以读取也可以写入(结合r/w/a使用)



注：

文本文件：r/w/a/+

二进制文件：rb/wb/ab/+

w模式下若无文件则创建文件



#### 编码格式

GB2312/GBK：中文字符编码

UTF-8：可变长度的编码，最常用





### 2.对文件读写操作 read()/write()

#### 读

##### read(n)

读取文件

n:表示读取的字符个数

seek(n)：重置文件指针到第n位置

n：大于等于0

常用seek(0)重置文件指针到开头位置



注：

```
f = open(r'D:\博客\python\python基础语法\附件资料\25\test1.txt')
print(f.read(4))
print(f.read(5))   # 读取文件中前5个字符
print(f.read(5))   # 上一次读取的位置，继续往后读取5个字符，读取不是重复内容
f.seek(0)
print(f.read(4))   # 文件指针回到文件的开头位置，重新读取文件内容
```

输出

```
hell
o wor
ld
11
hell
```





#####  readline()

读取文件的一行内容

若加入数字参数则与read(n)相似但遇到换行就立刻停

```
f = open(r'D:\博客\python\python基础语法\附件资料\25\test1.txt')
print(f.readline(17))
f.seek(0)
print(f.readline(16))
```

输出

```
hello world

hello world
```



##### readlines()

与 readline()类似但输出的是数组

默认情况下或readlines(0)，读取文件中全部的行

```
f = open(r'D:\博客\python\python基础语法\附件资料\25\test1.txt')
print(f.readlines())
f.seek(0)
print(f.readlines(0))
f.seek(0)
print(f.readlines(12))
f.seek(0)
print(f.readlines(13))
```

输出

```
['hello world\n', '111\n', '222\n', '333']
['hello world\n', '111\n', '222\n', '333']
['hello world\n', '111\n']
['hello world\n', '111\n']
```



#### 写

##### with 上下文管理器

进入 with 代码块：自动执行 打开 操作，退出 with 代码块：无论是否报错，都自动执行 关闭 操作

作用：

1.自动关闭文件 （不用写 `f.close()`）

2.即使报错，也能安全关闭（不会泄露资源）

3.代码更简洁、更安全

```
f = open("test.txt", "r", encoding="utf-8")
data = f.read()
f.close()

#等价于
with open("test.txt", "r", encoding="utf-8") as f:
    data = f.read()
```



##### w模式

进行数据的写入，新数据覆盖旧数据

##### a模式

进行数据的追加，新数据追加到旧数据之后

##### +模式

w+：进行数据的写入和读取

```
f.write('hello world')  # 数据写入之后，文件指针的位置在内容的最后
f.seek(0)
print(f.read())  # 从写入位置，继续往后读，读的是空行
```

r+：进行数据的读取和写入

```
f = open('test.txt', 'r+', encoding='utf-8')
print(f.read())  	# 先读取内容
f.write('hello')  	# 数据读取之后，文件指针的位置在内容的最后，再进行数据的写入，类似于追加的效果
```



示例

```
with open(r'D:\博客\python\python基础语法\附件资料\25\test1.txt', 'r') as f:
    a = f.read()  # str
    print(a)

with open(r'D:\博客\python\python基础语法\附件资料\25\test.txt', 'w',encoding='utf-8') as f:
    f.write(a)
    f.write('\n我爱python')
f = open(r'D:\博客\python\python基础语法\附件资料\25\test.txt', 'r', encoding='utf-8')

print(f.read())
```

输出

```
hello world
111
222
333
hello world
111
222
333
我爱python
```









### 3.关闭文件 close()

你打开文件后，系统会给它分配资源，用完必须关，否则：

1.文件一直被占用，删不掉、改不了

2.占用系统资源

3.数据可能没真正写入文件（丢失）
