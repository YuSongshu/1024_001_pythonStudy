## 面向对象

### 语法

```
class 类名:
    类代码

实例对象 = 类名()
```



类：抽抽象的概念名词，所有对象的集合

对象：是类的实例，类中具体的某一个对象

```
	类                      对象
# 金属类                 金、银、铁
# 水果类                 葡萄、香蕉
# 人类                  文心老师、冰冰老师、云舒老师
# 列表类 list            [1, 2, 3]   ['a', 'b', 'c']  创建的每一个列表，都是列表类下的对象
# 整数类 int            20  30  40  100
```


类名也是标识符的一种，推荐使用大驼峰命名法



示例

```
class Person:
	pass
	
# 创建对象 	
p1 = Person()
p2 = Person()

print(p1)  # <__main__.Person object at 0x00000205CB123EF0>  对象所在的内存地址
print(p2)  # <__main__.Person object at 0x00000205CB123E00>

```



## 属性

属性：类属性和实例属性

类属性：将变量定义在类中，称为类属性

实例属性：将变量定义在实例方法中，称为实例属性



### 类属性

```
 class Person:
     # 变量的定义和赋值
     name = '张三'
    
p1 = Person()
# 对象调用类中的属性
print(p1.name)
print(Person.name)
```

调用类中的属性能通过对象名.属性名	类名.属性名

​	



### 实例属性

```
class Person:
    def __init__(self, name):
        self.name = name   # 实例属性

p = Person("张三")
print(p.name)
# print(Person.name)     # 不能用类名直接访问实例属性
```

实例属性只能通过对象名.属性名





## 方法

定义在类中的函数，叫做方法

类方法和实例方法

### 类方法

定义：加 **@classmethod** 装饰器

第一个参数：**cls**（代表类本身）

没有 self

不能访问实例属性

```
class Student:
    # 类属性：所有学生共享
    total = 0

    def __init__(self, name):
        self.name = name
        # 每创建一个学生，总数+1
        Student.total += 1

    # 定义类方法
    @classmethod
    def show_total(cls):
        # cls 代表当前类，操作类属性
        print("学生总人数：", cls.total)



# 不用创建对象，直接类名调用类方法
Student.show_total()

# 创建实例
s1 = Student("小明")
s2 = Student("小红")

# 再次调用类方法查看总数
Student.show_total()

```



### 实例方法

定义在类中的函数，但是被实例对象调用的函数

带self

```
class Person:
    name = '张三'  # 类属性
    def func(self):
        # self 表示当前对象
        print(f"查看self的地址：{id(self)}")
        print('实例方法')
        # 在实例方法中，调用类属性
        print(f"输出类属性：{self.name}")  # 对象.类属性
        print(f"输出类属性：{Person.name}")  # 类名.类属性


# 创建对象
p1 = Person()
# 对象调用类属性
print(p1.name)
# 对象调用类中的实例方法
p1.func()
# 验证self和对象的地址是否一致
print(f"查看对象p1的地址：{id(p1)}")
```

输出

```
张三
查看self的地址：2432692573376
实例方法
输出类属性：张三
输出类属性：张三
查看对象p1的地址：2432692573376

```

self和对象的地址一致，故 Person.func(p1) = p1.func()



### 构造方法

含义：定义在类中的函数，在创建对象时自动执行

每个类都会有一个构造方法，默认的构造方法不执行任何代码

作用：在创建对象时初始化对象的实例属性

格式：

```
def __init__(self, ...)
```

示例

```
class Person:
    # 构造方法
    def __init__(self, name):
        # 把传入的name，绑定给当前对象的属性
        self.name = name
        
# 创建对象，括号里给name传值
p = Person("张三")

# 调用对象属性
print(p.name)
```



### 静态方法

不需要实例化对象就能调用

不需要 self

用 @staticmethod 装饰器声明

通常用于工具函数、通用处理

```
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    @staticmethod
    def is_valid_age(age):
        """静态方法：校验年龄是否合法（通用工具）"""
        return 0 < age < 150

# 调用：提前校验，再创建对象
age = 20
if User.is_valid_age(age):
    u = User("张三", age)
    print("用户创建成功")
```

















## 应用

```
class Student:
    school = '长工大'

    def __init__(self, name, age, sex, grade, course='python'):
        self.name = name
        self.age = age
        self.sex = sex
        self.grade = grade
        self.course = course

    def show(self):
        print(f"姓名：{self.name}，年龄：{self.age}，性别：{self.sex}，年级：{self.grade}，课程：{self.course}")

    def choose_course(self, new_course):
        print(f"{self.name} 原选修的是课程：{self.course}")
        self.course = new_course
        print(f"{self.name} 修改课程为：{new_course}")


def main():
    # 用列表存多个学生
    student_list = []

    while True:
        print("\n===== 学生信息管理系统 =====")
        print("1. 创建学生信息")
        print("2. 查看所有学生")
        print("3. 修改学生选修课程")
        print("0. 退出系统")
        print("=============================")

        choice = input("请输入功能编号：")

        if choice == "1":
            name = input("请输入姓名：")
            age = input("请输入年龄：")
            sex = input("请输入性别：")
            grade = input("请输入年级：")
            # 创建对象加入列表
            s = Student(name, age, sex, grade)
            student_list.append(s)
            print("学生信息创建成功！")

        elif choice == "2":
            if not student_list:
                print("暂无学生信息！")
            else:
                print("\n----- 所有学生信息 -----")
                # 遍历输出
                for idx, stu in enumerate(student_list):
                # enumerate(列表) 会把普通列表，自动变成一组一组的元组
                    print(f"第{idx+1}个学生：", end="")
                    stu.show()

        elif choice == "3":
            if not student_list:
                print("请先创建学生信息！")
            else:
                num = int(input("请输入要修改的学生序号(1/2/3...)："))
                # 转下标 -1
                idx = num - 1
                if 0 <= idx < len(student_list):
                    new_course = input("请输入新选修课程：")
                    student_list[idx].choose_course(new_course)
                else:
                    print("输入的序号不存在！")

        elif choice == "0":
            print("感谢使用，系统已退出！")
            break
        else:
            print("输入错误，请输入有效编号！")


if __name__ == '__main__':
    main()

### 魔术方法

#### 析构函数

对象被销毁时自动调用

程序结束 所有对象销毁，可通过 `del 对象名` 方法主动销毁

```
__del__()
```

作用：确保对象调用完成之后，会自动调用该方法，销毁对象，释放内存

```
class Person:
    def __init__(self, name):
        self.name = name
        print(f"创建对象：{self.name}")

    def __del__(self):
        print(f"销毁对象：{self.name}")

# 创建对象
p1 = Person("张三")
p2 = Person("李四")

print("----- 中间代码 -----")

# 手动销毁 p1
del p1

print("----- 程序结束 -----")
```

输出

```
创建对象：张三
创建对象：李四
----- 中间代码 -----
销毁对象：张三
----- 程序结束 -----
销毁对象：李四

```

运算符的重载

算术运算符重载与比较运算符重载

```
加：__add__(self, other)
减：__sub__(self, other)
乘：__mul__(self, other)
除：__truediv__()
```

```
相等：  __eq__(self, other)
不等：  __ne__(self, other)
大于：  __gt__(self, other)
大于等于：__ge__(self, other)
小于：   __lt__(self, other)
小于等于：__le__(self, other)
```

应用

```
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age
        
s1 = Student('李四', 18)
s2 = Student('小明', 22)

# print(s1 + s3)  # 对象不能直接进行算术运算，但某个属性可以进行算术运算

```



```
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __gt__(self, other):  # self当前对象，other是另外一个对象
        return self.age > other.age

    def __add__(self, other):
        return self.age + other.age


s1 = Student('李四', 18)
s2 = Student('小明', 22)
s3 = Student('小明', 19)
print(s1 > s2)  
print(s1 + s3)
```

```
False
37
