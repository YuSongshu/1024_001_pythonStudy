# 23_继承

继承：单继承、多继承

## 单继承

含义：单继承指一个子类(派生类)继承一个父类(基类)的所有属性和方法。

作用：通过继承，子类可以复用父类的代码，有助于减少代码冗余并提高代码的维护性。



格式：

```
class 父类:
    pass
class 子类(父类):
    pass
    
```

示例

```
class A:
    name = '父类属性'
	__money='私房钱'
	
    def f1(self):
        print('父类方法')


class B(A):
    pass

b = B()      #创建一个子类对象
# 子类可以调用父类的属性和方法
print(b.name)
b.f1()
#print(b.__money)		#报错私有的，子类不能继承、不能用
```

注：当某个属性不希望被子类继承时，可以将数据设置成私有数据





了解:

经典类：Python2.x中的类，不支持魔术方法，也不支持继承的传递性

新式类：Python3.x中的类，支持魔术方法，体现出继承的传递性



### 继承的传递性与重写

```
class GrandFather:
    name = '爷爷'

    def f1(self):
        print('爷爷方法')


class Father(GrandFather):
    name = '爸爸'  # 共有数据，共有属性
    # money = -10000  # 负债1万元，作为共有数据，子类可以继承的
    __money = -10000  # 负债1万元，作为私有数据，子类不能直接在类外访问

    def f2(self):
        print('爸爸方法')
        print(self.__money)  # 在类中可以访问私有属性


class Son(Father):
    name = '儿子'

    def f3(self):
        print('儿子方法')

```

Son => 直接继承 Father => 间接继承 Grandpa，这就是传递性

#### 重写

子类重新定义一个和父类同名的方法/属性，就会覆盖父类的版本，优先用子类自己的

作用：通过重写，子类可以给继承的方法提供自己新的实现功能

注：子类**方法**重写，必须定义一个跟父类同名、参数一致





#### super()重写

作用：重写不丢父类逻辑，还能加自己逻辑

与普通的父类名重写区别

1.父类名进行方法重写时，如果子类有多个父类，必须要具体指出是哪一个父类，写代码时容易混淆

2.super()进行方法重写时，不需要指明是哪一个父类，super()根据mro()继承顺序，来正确解析父类的方法，使代码更简单

super () => 代表父类

示例

```
class Person:
    def __init__(self, name, age, sex, height):
        self.name = name
        self.age = age
        self.sex = sex
        self.height = height

    def show(self):
        print(f"姓名：{self.name},年龄：{self.age},性别：{self.sex},身高：{self.height}")


class Student(Person):
    def __init__(self, name, age, sex, height, score, profession):
        # 子类的新增属性：score, profession
        self.name = name
        self.age = age
        self.sex = sex
        self.height = height
        
        super().__init__(name, age, sex, height)		# = Person.__init__(self, name, age, sex, height)
        self.score = score
        self.profession = profession

    def show(self):				# 重写show方法
        # 子类的新增属性：score, profession
        print(f"姓名：{self.name},年龄：{self.age},性别：{self.sex},身高：{self.height},成绩：{self.score},专业：{self.profession}")
        super().show()		# = Person.show(self)
        # 对父类中的方法进行扩展
        print(f"成绩：{self.score},专业：{self.profession}")


s1 = Student('小王', 18, '男', 180, 88, 'python')
s1.show()

```

输出

```
姓名：小王,年龄：18,性别：男,身高：180,成绩：88,专业：python
姓名：小王,年龄：18,性别：男,身高：180
成绩：88,专业：python
```







### 注

可以通过`__bases__`属性查看当前类继承的父类名，通过`__mro__`属性/  `mro()`方法查看当前类的继承的顺序

```
class GrandFather:
    pass


class Father(GrandFather):
    pass


class Son(Father):
    pass


print(Son.__bases__)
print(Father.__bases__)
print(GrandFather.__bases__)
print(Son.__mro__)
print(Son.mro())
```

输出

```
(<class '__main__.Father'>,)
(<class '__main__.GrandFather'>,)
(<class 'object'>,)
(<class '__main__.Son'>, <class '__main__.Father'>, <class '__main__.GrandFather'>, <class 'object'>)
[<class '__main__.Son'>, <class '__main__.Father'>, <class '__main__.GrandFather'>, <class 'object'>]

```







## 多继承

含义：一个子类可以继承多个父类，从而获得多个父类的属性和方法

语法：

```
class 父类名1:
    pass
class 父类名2:
    pass
class 子类名(父类名1, 父类名2):
    pass

```

示例

```
class A1:
    name = '张三'

    def f1(self):
        print('父类1的方法')


class A2:
    name = '李四'

    def f1(self):
        print('父类2的方法')


class B(A1, A2):  # 虽然同为子类的父类，但有先后顺序：从左向右
    pass
b = B()
print(b.name)
print(B.__mro__)
b.f1()

```

输出

```
张三
(<class '__main__.B'>, <class '__main__.A1'>, <class '__main__.A2'>, <class 'object'>)
父类1的方法
```



### 多继承的继承顺序

括号里从左向右

示例

class B(A1, A2)

继承的查找顺序：当前类自身的属性-->A1-->A2-->object





### 注

虽然子类通过多继承，可以获取多个父类的属性和方法，但是也容易出现冲突
