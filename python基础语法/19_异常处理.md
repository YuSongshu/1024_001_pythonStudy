# 19_异常处理

## 常见异常种类

1.NameError:使用一个还未被赋值的变量

 2.SyntaxError:代码不符合python语法规定

 3.IndexError:下标/索引超出范围

 4.ZeroDivisionError:除数不能为0

 5.KeyError:字典里不存在这个键

 6.AttributeError:对象没有这个属性

 7.ValueError:传入的值有错误

 8.TypeError:类型错误，传入的类型不匹配

 9.ModuleNotFoundError:无法引入模块或包

10.IndentationError:缩进错误;代码没有正确对齐



## 捕获处理异常

### try   except  else  finally

格式:

```
try:
    可能存在异常的代码
except 错误类型:
    存在错误类型1时执行的代码
else:
    没有出现异常时执行的代码
finally:
    不管有没有遇到异常都会执行的代码
```

 else  finally 可有可无



示例

```
while True:
    try:
        score_chinese = float(input('请输入语文分数：'))  # 容易报错的代码
        score_math = float(input('请输入数学分数：'))
        total_score = score_math + score_chinese  # 容易报错的代码
    
    # 专门捕获：输入不是数字的错误
    except ValueError:
        print('输入错误，只能输入数字')
        
    # 捕获其他所有未知异常（本质是牺牲性能用父类寻找异常）
    except Exception as e:  # 将捕获到的异常信息存放在变量e中
        print('注意数据类型的转换')
        print(f"捕获到的系统的异常提示信息：{e}")
    else:
        # 如果数据转换没有出现问题，成功打印成绩，且进行总分的计算
        print(f"成绩是：{score_chinese}")
        print(f"两科总分：{total_score}")
        # '88'+'65'=='8865'  -->  8865
        break
    finally:
        print('测试完成')


```



## 主动抛出异常

### raise

抛出的异常需要进行捕获(try)并处理(except)，需要对抛出的异常信息进行处理

示例

```
def login():
    username = input('请输入用户名：')
    password = input('请输入密码：')
    try:
        if len(password) < 8 or password.isalpha() or password.isdigit():
            raise Exception('密码安全性太低')  # 抛出异常后，函数也会结束掉
    except Exception as e:
        print(e)
    else:
        # 如果没有出现自定义的异常，则返回用户名和密码
        print(f"用户登录成功，用户名是：{username},密码是：{len(password) * '*'}")


# 异常在函数中已经处理，直接调用函数
login()
```



## 异常的传递

当一个函数内部抛出异常时，异常会沿着调用链向上传递，直到被except块捕获处理

如果没有找到处理异常的except块，程序奔溃

函数中出现异常，会逐层去找异常处理的except块，如果没有找到程序奔溃。

```
def a():
    int("abc")

def b():
    a()

def c():
    b()

# 在最外层捕获
try:
    c()
except ValueError:
    print("异常一层层传上来，被最外层接住")
```

核心规则

1. 函数内没 try-except，异常自动向上传递给调用者
2. 只要某一层 try 捕获到，异常就终止传递
3. 一直没人捕获，程序直接终止、报错



异常处理的位置

1.最底层函数中处理异常(异常开始的位置)

2.中间层函数异常异常(需要对异常进行封装，复杂不灵活)

3.在外层函数中处理异常(在外层调用，集中处理)

4.多层次处理异常(结构复杂，影响阅读和运行速率)

推荐使用第一种或第三种处理异常
