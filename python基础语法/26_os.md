# 26_os

os 是 Python内置标准库

用于文件 / 目录管理、路径处理、环境变量、系统命令等。

用前导包

```
import os
```



## 目录操作

```
os.getcwd()          # 获取当前工作目录（绝对路径）
os.chdir("path")     # 切换工作目录
os.listdir("path")   # 列出目录下所有文件/子目录
os.mkdir("test")     # 创建单级目录
os.makedirs("a/b/c") # 递归创建多级目录
os.rmdir("test")     # 删除空目录
os.removedirs("a/b/c") # 递归删除空目录
```

## 文件操作

```
os.remove("file.txt")  # 删除文件
os.rename("old.txt", "new.txt") # 重命名文件/目录
os.stat("file.txt")    # 获取文件元数据（大小、修改时间等）
```

## 路径处理（os.path，跨平台关键）

```
os.path.join("a", "b.txt") # 智能拼接路径（自动适配\或/）
os.path.exists("path")      # 判断路径是否存在
os.path.isfile("path")      # 判断是否为文件
os.path.isdir("path")       # 判断是否为目录
os.path.abspath("path")     # 转绝对路径
os.path.dirname("path")     # 获取目录名
os.path.basename("path")    # 获取文件名
```

## 遍历目录树

```
for root, dirs, files in os.walk("path"):
    print("当前目录：", root)
    print("子目录：", dirs)
    print("文件：", files)
```

## 其他常用功能

```
os.name          # 系统名称：nt(Windows)/posix(Linux/Mac)
os.environ       # 环境变量字典
os.system("cmd") # 执行系统命令（返回退出码）
```
