# 18_函数

## 初识

函数：把某个功能代码加载到内存空间，绑定给函数名

作用：代码重用、便于代码管理和维护

定义：

```
def 函数名():
    函数体
```

注：

1.函数在定义时不会执行，只有在调用函数时才会执行函数体中的代码

2.执行顺序：在调用函数时，找到函数定义的位置，执行函数体中的代码



示例

```
def login():
    username = input("请输入用户名:")
    password = input('请输入密码：')
    if username == 'admin' and password == '123456':  # 功能升级
        print('登录成功')
    else:
        print('登录失败')

# 函数调用
login()
```



## pass 占位符

作用：暂时替代函数体代码，避免出现语法问题报错

Python 是**缩进语法**，很多代码块（如 `if`/`for`/`def`/`class`）**后面必须跟至少一行缩进代码**，否则直接报错

加 `pass` 就合法了

```
def login():
    pass
```



## 函数注释

““”  ““”

在函数内第一行编写函数注释，解释函数体中函数的功能、参数、返回值





示例

```
def add(a, b):
    """求两个数的和"""
    x = 10
    return a + b

print(add(1, 2))
help(add)
```

输出

```
3
Help on function add in module __main__:

add(a, b)
    求两个数的和
```



函数里用 `"""..."""` 这种**函数文档注释**，**只能紧贴 def 下第一行**，换个位置就失效，变成普通字符串，不是函数注释了

加了单行注释也不行

```
def add(a, b):

    x = 10
    """求两个数的和"""# 这只是普通字符串，不是函数文档注释
    return a + b

print(add(1, 2))
help(add)
```

```
def add(a, b):
    # 单行注释
    """求两个数的和"""  # 照样不是标准函数文档注释
    return a + b
```







## 函数的参数

### 无参函数

使用场景：每次调用函数，执行的操作是固定的，更容易进行维护和测试，一般用于简单的打印；数据在函数内部进行输入



示例

```
def func():
    print("无参函数")
    username = input("请输入用户名：")
    password = input("请输入密码：")
    if username == 'admin' and password == '123456':
        print('登录成功')
    else:
        print('登录失败')
        
func()
```



### 有参函数

在定义是需要接收一个或读个形式参数，通过参数传递不同的值，可以控制函数的行为

```
def func2(username, password):  # 两个形式参数
    print("有参函数")
    if username == 'admin' and password == '123456':
        print('登录成功')
    else:
        print('登录失败')


# 调用函数
func2('admin', '123456')  # 传入两个实际参数

```



在调用函数是，必须按照形式参数定义的个数、顺序进行传参

Python 没有传统意义上的函数重载（不像 C++/Java 那样**同名不同参数**自动区分）。

```
def fn(x):
    print("一个参数")

def fn(x, y):
    print("两个参数")

fn(1)   # 报错！只会保留第二个 fn
```

注

变相实现 “重载” 的三种办法：

1.给参数设默认值 

```
def fn(x, y=None):
    if y is None:
        print("一个参数")
    else:
        print("两个参数")
```

2.可变参数 *args

```
def fn(*args):
    if len(args) == 1:
        print("一个参数")
    elif len(args) == 2:
        print("两个参数")
```

3.用类型注解 + 判断类型

```
def fn(x):
    if isinstance(x, int):
        print("整数")
    elif isinstance(x, str):
        print("字符串")
```



#### 位置参数

在调用函数是，必须按照形式参数定义的个数、顺序进行传参

如果实际参数和形式参数个数不一致，会报错；如果顺序不一致，数据输出可能会混淆

示例

```
def student(name, age):
	print(f"姓名：{name},年龄：{age}")
	
student("小王", 18)
student(18, "小王")		#数据输出混淆
# student(11, 18, "小王")		# 报错
```



#### 关键字参数

调用函数时，通过函数名指定传递的参数，参数顺序可以任意，但个数必须要一致

作用：不用管顺序

示例

```
def student(name, age):
    print(f"姓名：{name},年龄：{age}")


student(age=18,name='小明')
# student(age=18)	#报错


```



#### 默认参数

在调用函数时，如果没有给函数传参，默认使用函数定义时指定的默认值

位置参数必须在关键字参数前面，默认参数必须在参数的最后

```
def student(name, age,sex, height, weight, profession='计算机'):
    print(f"姓名：{name},年龄：{age},性别：{sex},身高：{height},体重：{weight},专业：{profession}")


student('小明', 18, '男', 177, 70)  # 没有给默认参数profession传值，使用默认值
student('小明', 18, '男', 177, 70, '会计')  # 新值覆盖旧值

```

输出

```
姓名：小明,年龄：18,性别：男,身高：177,体重：70,专业：计算机
姓名：小明,年龄：18,性别：男,身高：177,体重：70,专业：会计
```



#### 可变参数

把多余的**位置参数**打包成**元组 tuple**

允许函数接收任意个数的参数

`*args`：收**多个位置参数**   => 元组

`**kwargs`：收**多个关键字参数**   => 字典



示例

```
def add(*args):
    print(args, type(args))
    print(f"数字之和：{sum(args)}")  # sum(可迭代对象)


add()
add(10)
add(10, 22)

```

输出

```
() <class 'tuple'>
数字之和：0
(10,) <class 'tuple'>
数字之和：10
(10, 22) <class 'tuple'>
数字之和：32
```





```
def func(**kwargs):
    print(kwargs)

func(name="小明", age=18)
```

输出

```
{'name': '小明', 'age': 18}
```



注

混合使用顺序： 位置参数 → *args → 默认参数 → **kwargs

```
def f(x, *args, y=10, **kwargs):
    print("x =", x)
    print("args =", args)
    print("y =", y)
    print("kwargs =", kwargs)

f(1, 2, 3, y=99, a=100, b=200)
```

输出

```
x = 1
args = (2, 3)
y = 99
kwargs = {'a': 100, 'b': 200}
```









## 返回值

指函数执行执行完成后，返回给函数调用者的数据

作用：

1.数据传递：通过返回值，将函数中的数据传递到调用函数的位置

2.控制流程：可以根据函数的返回值，决定程序的下一步操作

3.代码重用：将返回值传递给其它函数使用



返回值类型：数值型、字符串、列表、元组等

返回值的个数：没有返回值、一个返回值、多个返回值



一旦函数执行到return位置，函数停止运行，将返回值返回给函数调用者，return下方代码不会执行

```
def scores(chinese, math, english):
    # 总分
    total_score = chinese + math + english
    # 获取平均分
    avg_score = total_score / 3
    return total_score, avg_score
    print('return下方的代码')  # 冗余代码，不会执行
    
# 返回值在控制台看不到-->希望在控制台看到返回值，使用print函数
print(scores(80, 90, 100))
```



注

函数中没有使用return，函数的返回值默认为None

```
def func(a, b):
    print('无返回值的函数')
    print(a + b)

func(10, 20)
print(func(10, 20))  # 使用print打印函数的返回值，输出结果为None
```



多个返回值时以元组形式存放

示例

```
def register():
    print('注册功能')
    username = input('请输入用户名：')
    password = input('请输入密码：')
    return username, password  # 元组 (username, password)


# 对元组解包
user_re, password_re = register()  # 定义两个变量，存放元组解包后的数据


# 将注册函数中的返回值传递到其它函数中使用
def login(u, p):  # 两个形式参数
    print('登录功能')
    user_inp = input('请输入用户名：')
    pwd_inp = input('请输入密码：')
    # 验证：用户输入的数据，和注册的数据是否一致
    if user_inp == u and pwd_inp == p:
        print('登录成功')
    else:
        print('登录失败')


login(user_re, password_re)  # 调用函数时，传入实际数据
```





## 作用域

概念：变量在程序中的可访问范围

python销毁机制：

在函数执行完成之后，函数内部定义的(局部)变量不再被保留，会被python垃圾回收机制自动清除。变量的使用仅限于函数内部，一旦函数执行完成，就会被销毁。

```
作用域一共有四种，范围从大到小依次是：
内置作用域、全局作用域、局部作用域、嵌套作用域。
1概念
内置作用域：python自定义的内置模块
全局作用域：py文件的内部
局部作用域：函数内部定义
嵌套作用域：一个函数嵌套另外一个函数
2加载 and 销毁
内置作用域：打开python解释器时被创建，关闭解释器销毁
全局作用域：运行.py文件被创建，执行完成被销毁
嵌套作用域：函数定义时被创建，函数调用完成后被销毁
局部作用域：函数定义时被创建，函数调用完成后被销毁
3加载 and 查找
加载：从大到小(从外向里)
查找：从小到大(从里向外)
```



### 全局作用域

定义在函数外的变量，在当前的整个.py都可以使用(在函数中可以使用)

函数里可以直接读取 ，但不能直接赋值改，想修改必须加 global

​	特殊情况：列表 / 字典。 但如果重新整体赋值，还是要 `global`

```
lst = [1,2,3]

def fun():
    lst.append(4)  # 改里面的内容，不用global

fun()
print(lst)
```

输出

```
[1, 2, 3, 4]
```



```
lst = [1,2]
def fun():
    global lst
    lst = [5,6]   # 重新赋值，必须global
    
fun()
print(lst)
```

输出

```
[5, 6]
```





### 局部作用域

变量定义在函数内部，函数执行完成后被销毁

函数内部的变量只能在函数内部使用

```
def func(x, y):
    s = x + y  # s定义在函数内部，局部变量，局部变量作用的范围-->局部作用域
    print(s)

func(1, 2)

# print(s)  # s局部变量，在函数外的全局作用域中，不能使用的NameError: name 's' is not defined,s变量没有被定义-->s变量在函数外不能使用
```

如何在函数外进行使用？

1.将局部变量返回出函数，将函数的返回值存放在函数外的变量中

```
def func(x, y):
    s = x + y  
    return s


a = func(1, 2)
print(a) 
```

2.global将局部变量修改为全局变量

global 变量名1, 变量名2

本质是声明，要写在使用之前

```
def func(x, y):
    global s
    s = x + y  # s定义在函数内部，局部变量，局部变量作用的范围-->局部作用域
    print(f"打印局部变量s:{s}")
    s2 = x*y
    print(f"打印局部变量s2:{s2}")


func(1, 2) 
print(f"使用global修改，直接在函数外使用定义在函数中的局部变量：{s}")  # 间接获取到函数中的变量s中的数据

```



### 嵌套的作用域

定义在嵌套函数中，变量的生效范围

```
def outer():
    x = 10

    def inner():
        nonlocal x   # 声明：用外层函数的x
        x = 20       # 修改外层的x

    inner()
    print("外层", x)

outer()
```



nonlocal ：将内层变量修改为外层变量，只影响上一层，不能作为全局变量

```
def outer():
    x = 10

    def inner():
        nonlocal x   # 声明：用外层函数的x
        x = 20       # 修改外层的x

    inner()
    print("外层", x)

outer()
```
