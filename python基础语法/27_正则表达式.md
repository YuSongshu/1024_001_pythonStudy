# 27_正则表达式

## 初识

在实际开发过程中经常会有查找符合某些复杂规则的字符串的 需要，比如:邮箱、图片地址，手机号码等，这时候想匹配或者 查找符合某些规则的字符串就可以使用正则表达式了。



概念：正则表达式就是记录文本规则的代码

优缺点：

1.正则表达式的语法很令人头疼﹐可读性差

2.正则表达式通用性很强﹐能够适用于很多编程语言



## 元字符

.   匹配除换行符以外的任意字符

\w   匹配字母或数字或下划线

\s   匹配任意的空白符

\d   匹配任意数字

\n   匹配一个换行符

\t   匹配一个制表符

^   匹配字符串的开始

$   匹配字符串的结尾

\W   匹配非字母或数字或下划线

\D   匹配非数字

\S   匹配非空白字符

a|b  匹配字符a或者字符b

()   匹配括号内的表达式，也表示一个组

[...] 匹配字符组中的字符

[^...] 匹配除了字符组中字符其他所有字符都匹配



量词：控制元字符出现的次数

\*  重复0次或者更多次

\+    重复1次或更多次

？    重复0次或者1次

{n}   匹配n次

{n,}  重复匹配n次或更多次

{n,m}  重复匹配n到m次



## re模块

在Python中需要通过正则表达式对字符串进行匹  配的时候，可以使用一个re模块

### 导入

```
import re
```



### 方法

#### re.findall(pattern, string)

pattern：正则表达式的匹配规则

string：待匹配的字符串

作用：输出所有条件的匹配结果，返回的是一个**字符串列表**

```
st = "hello 你好 python3.12.0！！"
pattern = r'\w'						# 匹配字母或数字或下划线
print(re.findall(pattern, st))
pattern = r'[a-zA-Z]'				# 匹配任意 1 个大小写英文字母
print(re.findall(pattern, st))		
```

输出

```
['h', 'e', 'l', 'l', 'o', '你', '好', 'p', 'y', 't', 'h', 'o', 'n', '3', '1', '2', '0']
['h', 'e', 'l', 'l', 'o', 'p', 'y', 't', 'h', 'o', 'n']
```

注

`a-zA-Z`中 - 连接单个字符

z与A间不能有空格否则会匹配空格



加入量词

```
st = "hello 你好 python3.12.0！！"
pattern = r'([a-z]+)\d'
print(re.findall(pattern, st))
```

输出

```
['python']
```



*与+的区别

*表示匹配0次或者多次，0次表示不匹配则返回空字符串

```
st = "hello 你好 python3.12.0！！"
pattern = r'\d*'  
print(re.findall(pattern, st))
```

输出

```
['', '', '', '', '', '', '', '', '', '', '', '', '', '', '', '3', '', '12', '', '0', '', '', '']
```



+表示匹配1次或者多次

```
st = "hello 你好 python3.12.0！！"
pattern = r'\d+'  
print(re.findall(pattern, st))
```

输出

```
['3', '12', '0']
```





#### re.match(pattern, string)

作用：只返回匹配到的第一个结果，否则返回None

```
st = "1hello 你好 python3.12.0！！"
pattern = r'\d+'
print(re.match(pattern, st))
```

输出

```
<re.Match object; span=(0, 1), match='1'>
```

span：匹配的下标从索引 0 开始，到索引 1 结束（取前不取尾）

match：实际匹配到的文本内容是字符



#### re.search(pattern, string)

作用：只返回匹配到的第一个结果，否则返回None

```
st = "hello 你好 python3.12.0！！"
pattern = r'\d+'
print(re.search(pattern, st))
```

输出

```
<re.Match object; span=(15, 16), match='3'>
```

span：匹配的下标从索引 0 开始，到索引 1 结束（取前不取尾）

match：实际匹配到的文本内容是字符





```
贪婪模式：在满足匹配的前提下，匹配尽可能多的/长的字符串  .*
.*：只要不是换行符，尽可能往长的字符去匹配
非贪婪模式：在满足匹配的前提下，匹配尽可能少的/短的字符串
.*?：只要不是换行符，尽可能往短的字符去匹配
```
