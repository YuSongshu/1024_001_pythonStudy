# 22_封装

三大特征：封装、继承、多态

## 封装

含义：面向对象编程的三大核心特征之一，它的核心思想是隐藏对象内部的实现细节，提高代码的安全性。

作用：

1.隐藏内部细节

把类里复杂的属性、内部逻辑隐藏起来，外部使用者不用关心内部怎么实现，只需要调用公开接口即可。

2.保护数据安全（最主要）

通过私有属性限制外部直接修改数据，避免数据被随意篡改、传入非法值，可在接口中做数据校验。

3.代码复用与整合（常用）

将数据（属性）和操作数据的方法统一封装在类中，代码结构清晰，方便重复使用。

4.降低维护成本

内部代码修改时，只要对外接口不变，外部调用的代码完全不用改动，减少 bug。



## 封装通过访问控制来实现

数据权限：共有数据、私有数据(类中使用)

### 共有数据

共有属性与共有方法

定义：没有下划线开头的变量 / 方法

谁都能访问、修改、调用

```
class Person:
    def __init__(self):
        self.name = "小明"  # 共有属性

    def say_hello(self):   # 共有方法
        print("你好")

p = Person()
print(p.name)   # 可以直接访问
p.say_hello()   # 可以直接调用
p.name = "小红" # 可以直接修改
print(p.name)
```





### 私有数据

私有属性与私有方法

定义：双下划线开头 `__变量名`

外部不能直接访问 / 修改，只能类内部使用

```
class Person:
    def __init__(self):
        self.__password = "123456"  # 私有属性

    def __secret(self):  # 私有方法
        print("内部秘密")

p = Person()
# print(p.__password)   # 报错！外部访问不了
# p.__secret()          # 报错！
```

作用

保护重要数据不被随意修改

封装内部逻辑，不让外部知道

外部如何访问？

通过类内公共方法输出私有属性与方法

```
class Person:
    def __init__(self):
        self.__password = "123456"  # 私有属性

    def __secret(self):  # 私有方法
        print("内部秘密")
    def show(self):
        self.__secret()
        print(self.__password)

p = Person()
p.show()
```



## @property 装饰器

@property 是 Python 内置装饰器，把方法伪装成属性，不用写 get/set 方法，就能灵活控制读取、修改、删除，还能做数据校验、计算

属性、只读保护。

读、写、删 都像**属性**一样用，而不是一堆方法，更简便

### 核心三部分（getter/setter/deleter）

@property → 读（getter，必写）

@属性名.setter → 改（setter，可选）

@属性名.deleter → 删（deleter，可选）

```
class Person:
    def __init__(self, name, age):
        self._name = name   # 私有属性（单下划线）
        self._age = age

    # 1. 读取属性（getter）
    @property
    def age(self):
        print("正在读取年龄...")
        return self._age

    # 2. 修改属性（setter，带校验）
    @age.setter
    def age(self, new_age):
        print("正在修改年龄...")
        if not isinstance(new_age, int):
            raise ValueError("年龄必须是整数")
        if new_age < 0 or new_age > 120:
            raise ValueError("年龄必须在 0-120 之间")
        self._age = new_age

    # 3. 删除属性（deleter）
    @age.deleter
    def age(self):
        print("正在删除年龄...")
        del self._age

# 使用
p = Person("小明", 20)

print(p.age)       # 读 → 触发@property
p.age = 25         # 改 → 触发@age.setter
del p.age          # 删 → 触发@age.deleter
```



私有+@property与公用的区别

读：限定读什么

写：限定写入的条件

```
class Person:
    def __init__(self):
        self.__age = 18
        self.__name = 'hys'

    @property       # 让你能读：p.age
    def age(self):
        return self.__age

    @age.setter     # 让你能写：p.age = 20
    def age(self, new_age):
        if new_age < 0 or new_age > 150:
            raise ValueError("年龄非法！")
        self.__age = new_age

p = Person()
print(p.age)
p.age = 20

```
