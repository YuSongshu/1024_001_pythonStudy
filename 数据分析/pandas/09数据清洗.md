## Pandas 清洗空值

如果我们要删除包含空字段的行，可以使用 **dropna()** 方法，语法格式如下：

```
DataFrame.dropna(axis=0, how='any', thresh=None, subset=None, inplace=False)
```

**参数说明：**

- axis：默认为 **0**，表示逢空值剔除整**行**，如果设置参数 **axis＝1** 表示逢空值去掉整**列**。
- how：默认为 **'any'** 如果一行（或一列）里任何一个数据有出现 NA 就去掉整行，如果设置 **how='all'** 一行（或列）都是 NA 才去掉这整行。
- thresh：设置需要多少非空值的数据才可以保留下来的。
- subset：设置想要检查的列。如果是多个列，可以使用列名的 list 作为参数。
- inplace：如果设置 True，将计算得到的值直接覆盖之前的值并返回 None，修改的是源数据。

我们可以通过 **isnull()** 判断各个单元格是否为空。

## mean()**、**median() 和 mode()

Pandas使用 **mean()**、**median()** 和 **mode()** 方法计算列的均值（所有值加起来的平均值）、中位数值（排序后排在中间的数）和众数（出现频率最高的数）。

```
# 中位数
import pandas as pd

a = [1,2,3,4,5]

df = pd.DataFrame(a)
print(df.median())
```

```
# 众数
import pandas as pd

a = [1,2,3,4,5,6,6]
b = [2,1,3,4,5,6]
df1 = pd.DataFrame(a)
df2 = pd.DataFrame(b)
print(df1.mode())
print(df2.mode())
```

输出：

```
   0
0  6


   0
0  1
```

排序默认从小到大

## Pandas 清洗格式错误数据

数据格式错误的单元格会使数据分析变得困难，甚至不可能。

我们可以通过包含空单元格的行，或者将列中的所有单元格转换为相同格式的数据。

以下实例会格式化日期：

### 日期格式错误

```
import pandas as pd

# 第三个日期格式错误
data = {
  "日期": ['2020/12/01', '2020/12/02' , '20201226','2020-01-01','2020.1.1','2020.01.01'],
  "客栈":['龙门客栈','同福客栈','京都客栈','桃源客栈','海角客栈','天涯客栈'],
  "营收": [50, 40, 45,30,20,70]
}

df = pd.DataFrame(data, index = ["0", "1", "2","3",'4','5'])

df['日期'] = pd.to_datetime(df['日期'], format='mixed')

print(df.to_string())
```

以上实例输出结果如下：

```
    日期    客栈  营收
0 2020-12-01  龙门客栈  50
1 2020-12-02  同福客栈  40
2 2020-12-26  京都客栈  45
3 2020-01-01  桃源客栈  30
4 2020-01-01  海角客栈  20
```

注：

`2020年12月01日`这种形式是无法转换为datetime形式的





## Pandas 清洗错误数据

数据错误也是很常见的情况，我们可以对错误的数据进行替换或移除。

以下实例会替换错误年龄的数据：

### loc定位修改数据

```
import pandas as pd

person = {
  "客栈": ['龙门客栈', '同福客栈' , '桃源客栈'],
  "营收": [50, 40, 123456789]    # 123456789 是错误的
}

df = pd.DataFrame(person)

df.loc[2, '营收'] = 30 # 修改数据

print(df.to_string())
```

输出：

```
     客栈  营收
0  龙门客栈  50
1  同福客栈  40
2  桃源客栈  30
```



### 设置条件语句

将 营收 大于 100 的设置为 100:

```
import pandas as pd

person = {
  "客栈": ['龙门客栈', '同福客栈' , '桃源客栈'],
  "营收": [8784654, 40, 123456789]    
}

df = pd.DataFrame(person)
df.loc[df['营收'] > 100, '营收'] = 100				# 将大于100的修改为100
print(df.to_string())
```

以上实例输出结果如下：

```
     客栈   营收
0  龙门客栈  100
1  同福客栈   40
2  桃源客栈  100
```



### 将错误数据的行删除

将 营收 大于 100 的删除:

```
import pandas as pd

person = {
  "客栈": ['龙门客栈', '同福客栈' , '桃源客栈'],
  "营收": [8784654, 40, 123456789]    # 将大于100的删除
}

df = pd.DataFrame(person)

for x in df.index:
    if df.loc[x, "营收"] > 100:
        df.drop(x,inplace=True)

print(df.to_string())
```

输出：

```
     客栈  营收
1  同福客栈  40
```

## Pandas 清洗重复数据

如果我们要清洗重复数据，可以使用 **duplicated()** 和 **drop_duplicates()** 方法。

### duplicated()

如果对应的数据是重复的，**duplicated()** 会返回 True，否则返回 False。

```
import pandas as pd

person = {
  "name": ['萧峰', '段誉', '段誉', '虚竹'],
  "age": [50, 40, 33, 23]  
}
df = pd.DataFrame(person)

print(df.duplicated())
```

输出：

```
0    False
1    False
2    False
3    False
dtype: bool
```

注：

只有对应数据都相等才会被判定为True



#### 也能通过`subset` 参数可指定 1 列 / 多列判断重复行

```
import pandas as pd

person = {
  "name": ['萧峰', '段誉', '段誉', '虚竹'],
  "age": [50, 40, 33, 23]  
}
df = pd.DataFrame(person)

print(df.duplicated(subset=['name']))
```




通过`keep`参数指定 **标记哪一行作为重复行**

| keep 参数     | 作用                                          | 筛选结果                        |
| ------------- | --------------------------------------------- | ------------------------------- |
| first（默认） | 保留第一次出现的行，标记后续重复行为 True     | 筛选出 “后续重复的副本行”       |
| last          | 保留最后一次出现的行，标记前面的重复行为 True | 筛选出 “前面的重复行”           |
| False         | 所有重复行都标记为 True                       | 筛选出 “所有重复行（含原始行）” |

注：保留False删除True



### drop_duplicates()

```
import pandas as pd

data = {
  "客栈": ['同福客栈', '同福客栈', '龙门客栈', '桃源客栈'],
  "营收": [40, 40, 40, 23]  
}

df = pd.DataFrame(data)

df.drop_duplicates(inplace = True)					# duplicated()为Ture才会删除
df.drop_duplicates(subset=['客栈'], keep='first')		# 指定某一列是否有重复值
print(df)		


# 如果不用inplace=True的替代方案:(赋值给用另个一变量)
# df1 = df.drop_duplicates(subset=['客栈'], keep='first')


```

以上实例输出结果如下：

```
    客栈  营收
0  同福客栈  40
2  龙门客栈  40
3  桃源客栈  23
```
