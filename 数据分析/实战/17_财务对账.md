how：默认是 how='any'：

df.dropna()： 只要有一个空值就整行删掉

### 只对 Source = Bank 的行，添加 Date 列的值

```
all_items.loc[all_items['Source']=='Bank','Date'] = all_items.loc[all_items['Source']=="Bank","Transaction Date"].apply(lambda x:str(x)[0:4]) + all_items.loc[all_items['Source']=="Bank","External Reference"].apply(lambda x:str(x)[15:19])                            
```

**[0:4]取前不取后**

**lambda 参数: 表达式** = Python 里的 “匿名小函数”，一句话就能定义，不用写 def、不用起名、自动 return。

```
# 普通函数（def）
def square(x):
    return x ** 2
# 等价 lambda
square = lambda x: x ** 2
# 调用一样
print(square(5))  # 25
```



### 把日期转成字符串

```
all_items.loc[all_items['Source'] == 'Book', 'Date'] = all_items.loc[all_items['Source'] == 'Book', 'Transaction Date'].apply(lambda x:x.strftime("%Y%m%d"))
```

**strftime ("% Y% m% d")** 日期格式化函数，把日期转成字符串：

```
2025-08-22
%Y → 年（4 位）：2025
%m → 月（2 位）：08
%d → 日（2 位）：22
组合 → 20250822
```

### 按行上下合并

```
all_items_book_bank = pd.concat([all_items_book_yl,all_items_bank_yl])        
#  pd.merge()    pd.concat()     pd.merge()=mysql:左右链接 left join、right join、inner join.....      pd.concat():union、union all（不去重，直接全拼）               
```

pd.concat([df1, df2, ...])拼接多个表			默认不去重，直接全拼

等价 SQL：`UNION ALL`（不去重，直接全拼）

UNION（去重）

```
# 拼接 + 重置索引 + 去重
all_items_book_bank = pd.concat([all_items_book_yl, all_items_bank_yl], ignore_index=True)
all_items_book_bank = all_items_book_bank.drop_duplicates()
```

ignore_index=True			（拼接后，重新给行编序号）

```
表1：0、1、2
表2：0、1
拼接后：0、1、2、3、4  ✅ 正常！
```

默认是 ignore_index=False

```
表1：0、1、2
表2：0、1
拼接后：0、1、2、0、1  ❌ 乱！
```



### 删除完全重复的行

作用：从 all_items_book_bank 中删除完全重复的行，返回去重后的新 DataFrame，赋值给 df_unique。

```
df_unique = all_items_book_bank.drop_duplicates(
    subset=None,        # 按哪些列去重，默认所有列,subset=['日期','金额']
    keep='first',       # 保留策略：'first'/'last'/False
    inplace=False,       # 是否直接改原表（不推荐）
    ignore_index=False   # 是否重置索引（0,1,2...）
)
```

keep='first'（默认）：留第一条

keep='last'：留最后一条

keep=False：所有重复行全删掉
