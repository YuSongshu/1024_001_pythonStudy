注：

import collections：python 内置的数据结构工具库里面有个超级好用的 **Counter** 计数器，能把列表里每个单词出现多少次全部统计出来

```
word_list = ["我", "你", "我", "他", "我", "你", "我", "苹果", "香蕉"]
data_pair = collections.Counter(word_list).most_common(3)
print(data_pair)
```

输出

```
[('我', 4), ('你', 2), ('他', 1)]
```

collections.Counter 常用方法 

**most_common(n)** ：取前 N 个高频元素

**elements()** ：把计数展开成原始列表

```
from collections import Counter
cnt = Counter(['a','a','b'])
print(list(cnt.elements()))
# 输出: ['a', 'a', 'b']
```

 **total()** ：所有计数总和

**subtract()** ：批量减去计数

```
cnt1 = Counter(a=3, b=2)
cnt2 = Counter(a=1, b=1)
cnt1.subtract(cnt2)
# cnt1 变成 Counter({'a':2, 'b':1})
```

**update()**：批量增加计数（同上理）



`Counter`还 支持**加减并交**运算
