# 分析报告

如何写好一份数据分析报告

1、要有一个好的框架（主题）

2、每个分析都有结论，而且结论一定要明确

3、分析结论不要太多要精；

4、分析结论一定要基于紧密严禁的数据分析推导过程； /完80% 未完成 20%

5、好的分析要有很强的可读性； 

​    1 言简意赅; 2 一图胜千言；3 图片不要太复杂；4 要有总结；



6、数据分析报告尽量图表化；

7、好的分析报告一定要有逻辑性；

​    1 拿国家级的权威数据；



8、好的分析一定是出自于了解产品（业务）的基础上的；

9、好的分析一定要基于可靠的数据源；

​	1 公司自有（excel）；

​	2 爬虫；

​	3 公司自有（mysql、Json、csv、txt）；

​	4 买数据---大公司；

​	5 来自公司的各种软件，出差系统、考勤系统、销售系统、财务系统、招聘系统.....数据孤岛 -  打通数据目的就是各个数据相关联

​    6 来自外部的ERP系统；



10、好的分析报告一定要有解决方案和建议方案；

11、不要害怕或回避“不良结论”；

12、不要创造太多难懂的名词/专业术语；

13、最后要感谢那些为你的这份分析报告付出努力做出贡献的人。

#### 缺失值

```
## 构建缺失值检测及处理函数
def na_check(df):
    if df.isna().sum().sum() == 0:
        return '无缺失值'
    else:
        na_num = df.isna().sum().sum()
        df.dropna(axis=0,inplace = True)
        return '含有缺失值，已处理'+str(na_num)+'个缺失值'
```

```
### 缺失值处理
print('数据集 nations ' + na_check(nations))
print('数据集 detailed ' + na_check(detailed))
```

数据集 nations 无缺失值
数据集 detailed 含有缺失值，已处理4320个缺失值

#### 重复值

```
def dup_check(df):
    if df.duplicated().sum() == 0:
        return '无重复值'
    else:
        dup_num = df.duplicated().sum()
        df.drop_duplicates(inplace=True)  # 移除 axis 参数
        return '含有重复值，已处理' + str(dup_num) + '个重复值'
```

```
print('数据集 nations ' + dup_check(nations))
print('数据集 detailed ' + dup_check(detailed))
```

数据集 nations 无重复值
数据集 detailed 含有重复值，已处理12个重复值
